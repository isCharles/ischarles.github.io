我以前对鉴权的态度有点随意。只要项目能跑，接口能调，页面能展示，就觉得主要功能完成了。

后来想公网部署时，这个想法马上站不住了。如果所有用户共用一套数据，那别人是不是能看到我的简历、面试记录、上传文件？如果接口只靠前端隐藏按钮，那直接调用 API 又怎么办？

这时我才意识到，鉴权不是“加一个登录页”。它至少涉及：

- 用户身份怎么确认
- token 怎么签发和刷新
- 每条数据属于谁
- 查询时是否自动带上 owner 条件
- 删除、导出、查看详情有没有越权检查

前端路由保护只能改善体验，不能代替后端校验。真正的边界必须落在服务端。

现在我看项目会多问一句：如果这个接口暴露在公网，陌生人能不能拿到不属于他的数据？

这个问题很朴素，但能筛出很多安全漏洞。
