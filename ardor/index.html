Ardor 是一个 AI 求职工作台。它把简历、面试记录、学习练习和日历连在一起，让准备接着上一次继续。Ardor is an AI career workspace. It connects your resume, interview notes, learning practice and calendar, so each preparation picks up where the last one left off.

01

求职记录Job search record

简历分析给出竞争力、能力雷达和按 A/B/C 分级的修改建议；写简历工作区让 Ardor 直接修改当前 LaTeX 版本，右侧即时预览。Resume analysis returns a competitiveness score, a skill radar and A/B/C-graded edits. The writing workspace lets Ardor edit the current LaTeX version with a live preview beside it.

02

面试复盘Interview review

每轮面试的备注、原始回答、反馈和薄弱点留在同一条记录里；复盘结果保留题目与表现，供下一轮准备使用。Notes, original answers, feedback and weak spots from every round stay in one record. Each review keeps the question and your performance for the next round.

03

定向学习Targeted learning

把面试暴露的问题变成课程、讲解和练习；每门课标注来源和准备目标，练习结果回到下一步安排。Weak spots from interviews become lessons, explanations and practice. Every course names its source and goal, and practice results feed the next step.

04

Agent 执行Agent execution

对话可以读取记录、提出修改；需要写入时，Ardor 先展示目标并等你确认。模型调用和工具步骤可以在轨迹里核对。The conversation can read records and propose changes. Before writing, Ardor shows the target and waits for your confirmation. Model calls and tool steps stay inspectable in the trace.

Ardor 仍在持续开发。源码和最新版本在 GitHub。Ardor is still in active development. Source and the latest releases are on GitHub.
